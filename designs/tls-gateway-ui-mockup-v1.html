新建隧道

同一条规则只需要选一次数据面；目标地址由那一端解析，不是你的本机。
借现有 SSH 通道，零部署；目标机是任意 SSH 服务器。
未注册的网关需先用一次性令牌注册（网关页）。
端口需为 1–65535 的整数
由网关解析并逐个校验 DNS 结果是否落在允许集内；不匹配则 OPEN_ERR denied-by-dns
