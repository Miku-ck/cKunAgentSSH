# Git 仓库子页 V3：双栏工作台（方案 A）+ SVG 车道图谱

日期：2026-10-25。前置：2026-10-24-git-tool-tab-design.md（V1 只读）、
2026-10-25-git-tab-actions-design.md（V2 写操作，弹窗形态）。

本 spec 记录 V3 的 UI 重构决策：六版可操作原型（双栏工作台 / 舰队看板 / 表格进化 /
混合工作台 / 巡检简报 / 键盘命令流）评审后选定**方案 A · 双栏工作台**落地。
数据层（注册表 / 取数 / 动作 / 审计 / 动作锁）与安全口径全部沿用 V1/V2，本次只动形态。

## 1. 布局：表格 + 弹窗 → 左列表 + 右常驻面板

- 左列（300px）：仓库按状态分组——**需处理**（读取失败 / 未提交变更 / 已分叉）、
  待拉取、待推送、无远程、干净；组头带计数且粘性，**需处理**组头用警示色。
  行内：名称 + 已加速标记，第二行分支（mono 青）+ ↑↓ + 未提交数；读取失败行红字。
  行是原生 `<button>`（键盘可达），选中 = 主色左缘条 + active 底。
- 右列：常驻详情面板 `GitRepoDetailPanel.vue`（替代 V2 的 `GitRepoDetailDialog`
  居中弹窗，后者删除）。头部 = 名称 + 状态徽标 + 路径 + 动作条（推送 / 获取 / 拉取 /
  终端 / 移出）；远程仓库带部署警示条；其下 = 变更 / 分支 / 图谱三页签。
- 选中态只存 `selectedId`，行数据经 computed 跟 `rows` 对齐——refresh 后面板自动
  换新对象，不再需要 V2 里「弹窗开着时同步行数据」的补丁。
- 未选中时右列为空态引导（双向居中，单行说明，不重复头部主操作）。
- 页面可见性：面板在页内（不 Teleport），切走不再需要收弹窗；回到前台仍 refresh 一次。

## 2. SVG 车道图谱（替代 --graph 文字档）

- `GIT_GRAPH_FORMAT` 尾部增 `%x1f%P`（父提交全哈希）；`GraphCommitRow` 增
  `parents: string[]`。本地与远程同一条格式串，主进程服务零改动。
- 新纯函数 `layoutGraphLanes(rows)`（shared，单测同源）：从最新到最旧单趟扫描，
  `lanes[i]` 记「下一个期望出现在车道 i 的哈希」；首父继承当前车道（主干延续），
  次父占空闲车道或汇入既有车道；父提交超出加载范围（-n 截断）跳过该边；
  无后续边的车道释放。只保留提交行——连接线行的拓扑已含在 parent 边里。
- `GitLaneGraph.vue`：车道列 SVG（同车道直落 / 跨车道三次贝塞尔）+ 圆点 + HEAD
  外环；车道色档五循环，色档类只声明局部令牌 `--glg-lane`，线/点用
  `stroke/fill: var(--glg-lane)`（填充描边可读强调色；文字色仍走 --accent-text 口径，
  variables.test.ts 守卫钉住）。引用徽章四档（HEAD 实底 / 本地紫 / 远端青 / 标签黄）
  与 V2 一致。
- 惰性取数从「折叠展开」平移为「页签首次激活」；加载更多 30 条 / 500 上限、
  失败回退平铺提交列表，全部沿用 V2。

## 3. 保持不变（V1/V2 口径）

- 取数通道：本地 `gitrepos:*` IPC；远程 `buildRemote*Cmd` 经 sshExec（读 20s /
  fetch 60s / pull 120s / 动作 60s；分批并发 4；epoch 守卫）。
- 动作安全：pull 固定 `--ff-only`（分叉不合并）；写操作确认框；远程写操作
  danger 确认 + `git_repo_action` 审计；`withBusy` 全局动作锁；分支名 / 提交信息 /
  pathspec 校验（isValidBranchName / isValidCommitMsg / isValidCommitFiles）。
- 行级取数失败：不发起详情取数（三段命令同样会失败），头部错误框 + 重试读取。
- 工具条（过滤 / 位置切换 / 连接远程 / 添加仓库 / 刷新）、错误带、加载带、
  空态引导、状态栏计数与 host 汇总，全部保留。

## 4. V3 仍不做（V2 边界未变）

stash、reset、clean、强推、删除 / 新建分支、解决冲突、diff 查看器、
统一总览（本地 + 远程混排，原型方案 B/D 的方向，留待后续）。
