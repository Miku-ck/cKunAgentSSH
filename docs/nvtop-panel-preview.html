修法与 --bg-terminal 同一决策：面板是固定深色的终端复刻，前景色与底色必须成对固定， 不能只固定其中一个（终端若跟随主题会变浅底浅字）。[data-theme="light"] 的 --bg-terminal 本身也是深色 #17181c，同一先例。

4 · 改动清单

  • 柱高几何编码量值 —— 抽为纯函数 fillPct(v, max)，柱高 = 归一后的量值；无历史数据的格子单独用暗格表示，与「值为 0」区分。新增 26 个单测锁定，其中一条专门断言 fillPct(0) !== fillPct(65)，防止退回「恒满高」。
  • 一行一指标 —— 原 nv-sys-col 把 MEM / SWP 夹在 CPU 图与 MEM 图之间，归属不可判。改为 名称 | 当前值 | 历史图 | 峰值 四栏网格。
  • 时间轴只留一条 —— 删除内联 Chart 组件与 4×6 个 ─xxx| 字符刻度，改为底部共享轴。
  • 补 Y 轴参考线（25 / 50 / 75）—— 原实现无任何纵向参照，「65.3% 有多高」不可读。
  • 负载补历史图 —— 新增 loadHist prop（由 DashboardView 透传）；负载非百分比，用 loadBandCls（4 / 8 经验阈值）与峰值 ×1.5 的动态上限。
  • SWP 用电平条而非趋势图 —— store 未保留 swap 历史，不伪造趋势，只表达当前值。
  • 矛盾态显式化 —— 负载高 / CPU 低 → 疑似 IO 等待；SWAP ≥ 95% → 换页压力；显存占用而算力近零 → 占卡不干活。判定与文案是纯函数 detectDivergences，有边界单测。
  • 单位补全 —— MEM: 200.0GiB (79.5%) 里的 200.0 是 used 却没给总量，易被读成总量；改为 200.0 / 251.6 GiB。
  • 调色板集中 —— 15 个 --nv-* 组件局部令牌取代散落在 37 条规则里的裸 hex（原含 #050505 / #3a3a3a / #7c7c7c 等）。
  • 补底轨 —— 原 .nv-blocks 无背景，图区在无数据时完全不可见；现加 --nv-track 底轨。
  • 布局缺陷修复 —— .nv-blocks 原为 inline-flex，在系统区里父级是普通块容器，会触发 shrink-to-fit 导致宽度退化为约 119px；改为块级 flex 后撑满整列。
  • 窄窗口 —— <860px 收窄固定列，优先保留图区。
