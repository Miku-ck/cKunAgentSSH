状态

  • 默认：图标 --text-secondary，无底色
  • hover：--bg-hover 底 + --text-primary 图标
  • 展开：--accent-indigo-bg 底 + indigo 图标，+ 号旋转 45° 变 ×（同一按钮闭合）
  • 焦点：focus-visible 2px 主色描边，键盘可见
  • 禁用：Agent 运行中沿用 :disabled 半透明，与上传按钮一致

交互

  • 点击开合；Esc 关闭并把焦点交还 + 号；点击菜单外区域关闭
  • ↑ ↓ 移动高亮，Enter 选中，Tab 同 Enter（对齐既有 / 技能菜单手感）
  • 选中后菜单关闭，能力以 chip 形式出现在输入框上方（复用现有 skill tag 视觉）

无障碍

  • 触发按钮：aria-haspopup="menu" + aria-expanded + aria-controls
  • 菜单：role="menu"，条目 role="menuitem"，方向键与 Tab 可达
  • 点击热区 24×24（图标按钮允许下限 24px；如需触屏可放宽到 28px）
